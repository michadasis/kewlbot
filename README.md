A fun and moderation Discord bot built with **discord.js v14** and slash commands.

## Features

- Full slash command support (discord.js v14)
- Fun commands with GIF reactions
- Complete moderation suite (ban, kick, mute, warn, and more)
- Poll creation with reaction voting
- Suggestion system with accept/deny reactions
- Dynamic `/help` command that auto-generates from your command files
- Auto-registers slash commands on startup
- Express keep-alive server (for hosting on platforms like Glitch or Replit)

| `/suggest <suggestion>` | Submit a suggestion to the suggestions channel |
| `/unafk` | Remove your AFK status |
| `/userinfo [@user]` | Get info about a user |

### Moderation

> All moderation commands are only visible to members with the required permissions.

| Command | Required Permission | Description |
|---|---|---|
| `/ban <user> [reason]` | Ban Members | Permanently ban a member |
| `/kick <user> [reason]` | Kick Members | Kick a member from the server |
| `/clear <amount>` | Manage Messages | Bulk delete 1 to 100 messages |
| `/mute <user> [reason]` | Manage Roles | Add the Muted role to a member |
| `/unmute <user>` | Manage Roles | Remove the Muted role from a member |
| `/tempban <user> <duration> [reason]` | Ban Members | Temporarily ban (e.g. 1h, 30m, 1d) |
| `/tempmute <user> <duration> [reason]` | Manage Roles | Temporarily mute a member |
| `/unban <userid> [reason]` | Ban Members | Unban a user by their ID |
| `/warn <user> <reason>` | Ban Members | Send a warning DM to a member |

> Note: For `/mute`, `/unmute`, and `/tempmute` to work, you must have a role named exactly **Muted** in your server with the appropriate channel permission overwrites set up.

## Permissions

The bot requires the following Discord permissions to function fully:

| Permission | Used For |
|---|---|
| Send Messages | Responding to commands |
| Embed Links | Sending rich embeds |
| Read Message History | Bulk delete (clear command) |
| Manage Messages | Bulk delete, removing reactions |
| Manage Channels | Nuke command |
| Manage Roles | Mute and unmute commands |
| Kick Members | Kick command |
| Ban Members | Ban, tempban, and unban commands |
| Add Reactions | Poll and suggestion reactions |
| Manage Nicknames | AFK, nickme, and unafk commands |
